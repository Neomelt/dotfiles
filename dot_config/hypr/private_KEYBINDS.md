# Hyprland 快捷键

## 键名说明

- **SUPER**：就是 **Windows 键**（⊞），在左下角 `Ctrl` 和 `Alt` 之间。
- **Return**：就是 **Enter / 回车键**，主键盘区右边最大的那个键；笔记本上在右 `Shift` 上方。
- **Esc**：键盘左上角，写着 `Esc`。
- **Tab**：`Caps Lock` 上面、带两个箭头的键。
- **Space**：空格键。

## 最常用

| 快捷键 | 作用 |
| --- | --- |
| `SUPER + 回车（Enter）` | 打开终端（kitty） |
| `Ctrl + Alt + T` | 打开终端（备用，和 Ubuntu 一样） |
| `SUPER + D` | 应用启动器：打字搜索，↑↓ 或 Ctrl+J/K 选，回车打开；常用的排前面 |
| `SUPER + C` | 剪贴板历史：文字和图片都有，回车复制，Shift+Del 删一条 |
| ``SUPER + ` `` | 下拉终端（Esc 左边那个键），再按一次收起，点别处也会收起 |
| `SUPER + E` | 文件管理器（Dolphin） |
| `SUPER + Q` | 关闭当前窗口 |
| `SUPER + Tab` | 切换到下一个窗口 |
| `F1` | 显示这份帮助 |
| `SUPER + Esc` | 锁屏，2 秒后熄屏；动鼠标或按键亮屏 |
| `SUPER + Shift + P` | 电源面板（锁屏 / 睡眠 / 注销 / 重启 / 关机） |
| `SUPER + V` | 语音输入（按一次录音，再按一次转写并粘贴） |
| `SUPER + Shift + E` | 直接退出 Hyprland，回到登录界面 |

## 顶栏

顶栏平时隐藏；鼠标碰到**屏幕顶部中间**（300×3px 热区）就出现，移开 1.2 秒收起；有面板开着时不收。

从左到右：

- **圆点**：工作区。长条是当前，亮点是有窗口的，点击切换
- **正在播放**（有播放器时）：点击打开媒体面板（封面、进度条、上一首/播放/下一首）；中键直接播放/暂停
- **时间**：点击打开日历
- **托盘图标**：QQ / Clash Verge / fcitx 等；左键激活，右键菜单
- **Wi-Fi**：网络面板。开关 Wi-Fi、选网络、直接输密码连接；点已连接的网络可以断开或忘记
- **音量**：声音面板。输出/输入音量、切换输出和输入设备、每个应用单独调音量；**滚轮**直接调音量，**右键**静音
- **铃铛**：通知中心。有未读时右上角有蓝点，勿扰时铃铛带斜线
- **齿轮**：设置面板。亮度、音量、Wi-Fi、勿扰、保持亮屏、录屏、区域截图、快捷键、系统设置
- **电池**：点击同齿轮
- **电源**：电源面板。注销 / 重启 / 关机要**点两次**才执行，防误触

所有面板：**点面板外面任何地方或按 Esc 关闭**；面板开着时点顶栏上另一个按钮会直接切过去。

按音量键、亮度键时，dock 上方会弹出一个提示条，一秒多后自己消失。

## 终端小工具

| 命令 / 按键 | 作用 |
| --- | --- |
| `Ctrl + R` | 模糊搜索命令历史（fzf） |
| `Ctrl + T` | 模糊搜索文件，右边预览内容，回车插入路径 |
| `Alt + C` | 模糊搜索子目录并进入 |
| `z 关键词` / `zi` | 跳到常去的目录 / 列出来挑一个（zoxide） |
| `y` | yazi 文件管理器，能预览图片、视频、PDF；退出后停在最后的目录 |
| `ls` `ll` `la` `lt` | 带图标的列表 / 详细 / 含隐藏文件 / 树状（eza） |
| `cat 文件` | 带高亮显示（bat）；要原版用 `\cat` |
| `btop` | 系统监视器，`q` 退出 |
| `lg` | lazygit，终端里的 git 界面 |
| `kitten icat 图片` | 在终端里直接显示图片 |
| `Ctrl + Shift + E` | 给屏幕上的链接标字母，按字母打开 |

配置在 `~/.config/zsh/tools.zsh`。

## 中文输入

- `Ctrl + Space` 切换中英文（fcitx5）

## 找不到东西时

- `SUPER + D` 里输入英文名：`konsole`、`dolphin`、`firefox`、`systemsettings`…
- 终端里运行 `hyprctl binds`：列出所有快捷键
- 终端里运行 `mugzx-status`：查看顶栏 / 壁纸 / 进程状态
- 终端里运行 `qs ipc -p ~/.config/quickshell/mugzx call panels toggle volume`：用命令开关面板（`volume` / `wifi` / `control` / `power` / `calendar` / `media`）
- 终端里运行 `hyprctl clients`：查看窗口列表

## 注意

- 自动锁屏：5 分钟不操作就锁屏，再过 5 秒熄屏。看视频不想熄屏，在设置面板打开“保持亮屏”。
- 通知中心（SwayNC）从右上角弹出，点外面或按 Esc 关闭。配置在 `~/.config/swaync/`。
- 顶栏代码在 `~/.config/quickshell/mugzx/`，改完保存 Quickshell 会自动重载。旧版备份在 `~/.config/quickshell/mugzx.bak-20261026-143431/`。
- 顶栏没了：终端运行 `mugzx-startup &` 重新拉起；`SUPER + Shift + P` 在顶栏没运行时会退回旧的 wofi 电源菜单。
- 如果重启后 QQ 托盘图标没出现，把 QQ 重启一次即可（QQ 需要在托盘宿主启动后再注册）。
- 底部 Dock：每个应用只占一个图标，下面的小点是打开的窗口数，当前窗口的点是蓝色长条。
  - **左键**：没打开就启动；打开了就切过去，有多个窗口时再点一次切到下一个
  - **中键**：再开一个新窗口
  - **右键**：菜单。列出这个应用的所有窗口（点一下切过去，× 关闭），把窗口移到某个工作区，新建窗口，固定 / 取消固定，关闭全部
  - 固定列表在 `~/.config/mugzx/dock-pinned`，一行一个 .desktop 文件名（不带 `.desktop`），改完自动生效；一般直接用右键菜单的“固定到 Dock”就行
- 截图标注（satty）：`Enter` 保存 + 复制并退出，`Esc` 取消，右键复制。截图在 `~/Pictures/Screenshots`，录屏在 `~/Videos/Recordings`。
- 语音：`qwen-voice` 服务随登录启动，识别完会自动粘贴。
